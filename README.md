# SNOWMOON CHAPTER 1 — AI ANIME PRODUCTION PACKAGE

This package contains the production assets and prompts for a 2-minute cinematic AI-anime adaptation of Chapter 1.

## Structure
01_CHARACTER_DESIGNS — character reference crops + master sheet
02_BACKGROUND — environment reference images
03_STORYBOARD — storyboard PDF
04_IMAGE_PROMPTS — one keyframe prompt per scene
05_VIDEO_PROMPTS — one animation prompt per scene
06_VOICE — dialogue/performance scripts
07_AUDIO — sound design plan
08_EDIT — editing/timeline plan
09_FINAL — final render location

## Scene plan
12 scenes x 10 seconds = 120 seconds.

## Continuity
Use CHARACTER_SHEET_MASTER.png as the primary visual reference.
Gladias must retain:
- dark brown hair
- calm intelligent eyes
- dark purple Veridian Privacy Robe
- matching dark purple shoes
- futuristic hand device
- same facial proportions

## Voice
The package contains voice direction and scripts. Actual recorded/synthesized voice files are intentionally not fabricated; add WAV/MP3 files to 07_AUDIO after recording or voice generation.

## Final video
Snowmoon_Chapter1.mp4 is the final render target. A completed 2-minute animated render cannot be truthfully included without running a video-generation/rendering pipeline. The package is prepared so the scene clips can be rendered and assembled directly.

## Important
Some visual elements in this package are concept/reference assets. For final bounty submission, replace them with the highest-quality generated scene frames/video clips from your chosen image/video model.
